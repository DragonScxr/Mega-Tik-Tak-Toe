# Mega Tic-Tac-Toe

Pass-and-play Ultimate Tic-Tac-Toe. Nine mini-boards sit inside one large board. The cell you play sends your opponent to the matching mini-board. A won or drawn mini-board lets them play in any board that is still open. Three mini-boards in a row wins the game.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
